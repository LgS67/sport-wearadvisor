Archivio e sicurezza

Versione locale con salvataggio sul dispositivo e backup manuale. I dati sono salvati nel browser su questo dispositivo, non su OneDrive. Potrebbero andare persi cancellando i dati del browser o aprendo il file in un altro ambiente. Dopo ogni sessione premi Esporta archivio JSON e salva il file su OneDrive. Il file contiene anche le fotografie. Un file HTML aperto nell’anteprima di ChatGPT può bloccare pulsanti e salvataggi. Non cancellare dati Safari e non usare navigazione privata.
